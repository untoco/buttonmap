# BMW K-CAN2 Buttonmap

`buttonmap` назначает двум кнопкам Free-to-Use (FTU) на руле JQ Werks Madtrace функции автомобиля по K-CAN2. Первое назначение - однократные команды перехода к предыдущему и следующему треку в медиасистеме BMW. Входы и CAN-команды вынесены отдельно, поэтому в дальнейшем им можно задать другие подтверждённые функции. AtomS3R с Atomic DIY Proto Kit принимает два сухих контакта через съёмный разъём, а отдельный Unit CAN отправляет настроенные кадры в K-CAN2.

> **Граница безопасности.** Проект передаёт кадры CAN, а не только читает шину. Сначала соберите и проверьте его на стенде, затем подключайте только к нужной паре K-CAN2. Не подключайте к PT-CAN, проводке подушки безопасности или SRS. Перед работой около подушки безопасности отсоедините минусовую клемму аккумулятора и не смещайте центральное положение контактного кольца руля.

## Первое назначение и границы проверки

| Пункт | Статус | Основание |
| --- | --- | --- |
| Два независимых сигнала кнопок FTU используют один общий провод. | Подтверждено приложенным руководством JQ. | FTU #1 - красный/белый; FTU #2 - жёлтый/зелёный. |
| Команда «предыдущий трек» | Получена от пользователя и принята для проекта. | Стандартный CAN `0x0A3`, DLC 2: `[FD FF]`. |
| Команда «следующий трек» | Получена от пользователя и принята для проекта. | Стандартный CAN `0x0A3`, DLC 2: `[FE FF]`. |
| Нейтральная команда | Получена от пользователя и принята для проекта. | Стандартный CAN `0x0A3`, DLC 2: `[FC FF]`. |
| Скорость K-CAN2 | Допущение конфигурации. | `100 кбит/с`; до подключения в нормальном режиме подтвердите пассивным захватом на этой машине. |
| DLC кадров и пауза до нейтрали | Требует стендовой проверки. | Прошивка использует DLC 2 и отправляет нейтраль через 80 мс после нажатия. |
| Компонентная конфигурация | Зафиксировано. | AtomS3R + Atomic DIY Proto Kit A077 + Unit CAN U085. |

## Оборудование

| Количество | Модуль | Назначение |
| ---: | --- | --- |
| 1 | M5Stack AtomS3R | Контроллер с экраном для диагностики. |
| 1 | M5Stack Atomic DIY Proto Kit, A077 | Нижняя протобаза для однократной разводки трёх входов на 4-контактный съёмный разъём VH3.96. |
| 1 | M5Stack Unit CAN, U085 | Изолированный CAN-трансивер CA-IS3050G в Grove-порту. |
| 1 | Grove-кабель 20 см | Соединяет AtomS3R с Unit CAN. |
| 1 | Ответная колодка VH3.96 4P с обжимными контактами | Входит в A077; в неё обжимаются три штатных провода FTU. |
| 1 | Штатный трёхпроводный жгут FTU руля JQ | Подключается съёмно к ответной колодке VH3.96. |

В этой конфигурации Grove-порт AtomS3R полностью занят Unit CAN: `G2/GPIO2` - CAN TX, `G1/GPIO1` - CAN RX. Atomic DIY Proto Kit A077 установлен снизу AtomS3R. Это именно протобаза: назначение контактов её разъёма VH3.96 задаётся при однократной сборке A077. На плате нужно развести `G5`, `G6` и `GND` AtomS3R на три контакта VH3.96, а четвёртый оставить свободным. Провода FTU после этого лишь обжимаются в ответной части колодки — пайка жгута руля не нужна. Входы используют внутреннюю подтяжку к питанию; при нажатии кнопка замыкает вход на общий провод FTU/GND.

```text
Общий провод JQ FTU ─────────────────────── A077 VH3.96: контакт, разведённый на GND
JQ FTU #1, красный/белый (предыдущий) ───── A077 VH3.96: контакт, разведённый на G5
JQ FTU #2, жёлтый/зелёный (следующий) ───── A077 VH3.96: контакт, разведённый на G6
Четвёртый контакт VH3.96 ────────────────── не подключать

AtomS3R Grove (G2/G1) ───────────────────── Unit CAN U085
Unit CAN CAN-H / CAN-L ───────────────────── K-CAN2 CAN-H / CAN-L
```

**До первого включения прозвоните A077:** выбранный контакт VH3.96 должен иметь связь только с `GND`, `G5` или `G6` соответственно; между ними не должно быть короткого замыкания. У A077 разъём обжимной VH3.96, а не винтовой. **Не соединяйте** общий провод FTU с кузовом автомобиля, 12 В, проводом CAN или цепью подушки безопасности/SRS. Когда руль отсоединён, проверьте мультиметром все три провода со стороны руля: каждая кнопка должна замыкать только свой сигнальный провод с общим. При длинном или зашумлённом кабеле добавьте компактный автомобильный формирователь входов либо хотя бы проверьте работу внутренних подтяжек и антидребезга на реальном жгуте до окончательной установки. Unit CAN будет ответвлением существующей K-CAN2, поэтому штатный резистор 120 Ом из его комплекта не устанавливайте без отдельного подтверждения, что точка является концом шины.

## Начальное поведение

После нажатия с антидребезгом `buttonmap` отправляет соответствующую команду один раз, ждёт 80 мс и отправляет нейтраль. Удержание кнопки не листает треки повторно. Экран AtomS3R показывает `PREVIOUS`, `NEXT`, `READY` или ошибку передачи/шины. Поставленный в очередь кадр не доказывает, что команда принята: на стенде проверьте трассу K-CAN2 и реакцию iDrive.

В исходном коде первое назначение называется `previous`/`next`. Новые функции автомобиля добавляйте в `include/buttonmap_config.h` только вместе с подтверждённым CAN-кадром, правилом нейтрального значения и записью в плане стендовой проверки. Кадр, найденный для одной функции, нельзя считать подходящим для другой.

## План стендовой проверки

1. На выключенном контроллере, не подключённом к автомобилю, прозвоните разводку A077 (`GND`, `G5`, `G6`) до контактов VH3.96, затем проверьте общий провод FTU и контакты обеих кнопок.
2. Подайте на Atom питание по USB. По трассе CAN-анализатора убедитесь, что каждое нажатие даёт ровно одну команду и `[FC FF]` через 80 мс.
3. На целевой машине сначала пассивно запишите K-CAN2. Подтвердите скорость 100 кбит/с, стандартный ID `0x0A3`, DLC 2 и отсутствие конфликтующего кадра от другого блока.
4. Только после этого подключите Unit CAN в нормальном режиме и проверяйте по одной команде со стабильным питанием. Если команда не работает, отключите модуль и вернитесь к пассивному захвату; не подбирайте другие шины или ID.

## Сборка и загрузка

```bash
git clone https://github.com/untoco/buttonmap.git
cd buttonmap
python3 -m venv .tooling/platformio
.tooling/platformio/bin/python -m pip install --upgrade pip "platformio==6.1.19"
.tooling/platformio/bin/pio run
.tooling/platformio/bin/pio device list
.tooling/platformio/bin/pio run --target upload --upload-port /dev/cu.usbmodem101
```

Используйте фактический порт из вывода `pio device list`: указанный в примере порт не универсален. Проект намеренно не загружает прошивку автоматически.

## Источники

- Руководство JQ Werks Madtrace, приложенное к задаче: обозначение проводов FTU #1/FTU #2 и предупреждения производителя по подушке безопасности и контактному кольцу.
- [Документация M5Stack Atomic DIY Proto Kit A077](https://docs.m5stack.com/en/atom/atomic): нижняя протобаза и разъём VH3.96.
- [Документация M5Stack Unit CAN](https://docs.m5stack.com/en/unit/can): изолированный CA-IS3050G, Grove и CAN-интерфейсы.
- [API Espressif TWAI](https://docs.espressif.com/projects/esp-idf/en/stable/esp32s3/api-reference/peripherals/twai.html): передача в нормальном режиме и обработка состояния bus-off.
