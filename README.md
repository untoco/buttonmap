# BMW K-CAN2 Buttonmap

`buttonmap` назначает двум кнопкам Free-to-Use (FTU) на руле JQ Werks Madtrace функции автомобиля по K-CAN2. Первое назначение - однократные команды перехода к предыдущему и следующему треку в медиасистеме BMW. Входы и CAN-команды вынесены отдельно, поэтому в дальнейшем им можно задать другие подтверждённые функции. Atomic CAN Base отправляет настроенные кадры в K-CAN2, а Unit 3.96 принимает два сухих контакта через винтовую клемму.

> **Граница безопасности.** Проект передаёт кадры CAN, а не только читает шину. Сначала соберите и проверьте его на стенде, затем подключайте только к нужной паре K-CAN2. Не подключайте к PT-CAN, проводке подушки безопасности или SRS. Перед работой около подушки безопасности отсоедините минусовую клемму аккумулятора и не смещайте центральное положение контактного кольца руля.

## Первое назначение и границы проверки

| Пункт | Статус | Основание |
| --- | --- | --- |
| Два независимых сигнала кнопок FTU используют один общий провод. | Подтверждено приложенным руководством JQ. | FTU #1 - красный/белый; FTU #2 - жёлтый/зелёный. |
| Команда «предыдущий трек» | Получена от пользователя и принята для проекта. | Стандартный CAN `0x0A3`, DLC 2: `[FD FF]`. |
| Команда «следующий трек» | Получена от пользователя и принята для проекта. | Стандартный CAN `0x0A3`, DLC 2: `[FE FF]`. |
| Нейтральная команда | Получена от пользователя и принята для проекта. | Стандартный CAN `0x0A3`, DLC 2: `[FC FF]`. |
| Скорость K-CAN2 | Допущение музыкального пресета. | `100 кбит/с`; до подключения в нормальном режиме подтвердите пассивным захватом на этой машине. |
| DLC кадров и пауза до нейтрали | Требует стендовой проверки. | Музыкальный пресет использует DLC 2 и отправляет нейтраль через 80 мс после нажатия. |
| Компонентная конфигурация | Зафиксировано. | AtomS3R + Atomic CAN Base A103 + Unit 3.96 U020. |

## Оборудование

| Количество | Модуль | Назначение |
| ---: | --- | --- |
| 1 | M5Stack AtomS3R | Контроллер с экраном для диагностики. |
| 1 | M5Stack Atomic CANBus Base, A103 | Нижняя CAN-база с изолированным трансивером CA-IS3050G. |
| 1 | M5Stack Unit 3.96, U020 | Переходник Grove ↔ VH3.96-4P с съёмной винтовой клеммой для кнопок. |
| 1 | Grove-кабель 20 см | Соединяет AtomS3R с U020; входит в комплект U020. |
| 1 | Штатный трёхпроводный жгут FTU руля JQ | Вставляется в винтовую клемму U020. |

Atomic CAN Base A103 установлен снизу AtomS3R и использует `G5/GPIO5` для CAN TX и `G6/GPIO6` для CAN RX. Верхний Grove-порт остаётся для U020: `G2/GPIO2` - FTU #1, `G1/GPIO1` - FTU #2. Три штатных провода FTU вставляются в винтовую клемму U020: пайка, протоплата и обжим не нужны. Входы используют внутреннюю подтяжку к питанию; при нажатии кнопка замыкает вход на общий провод FTU/GND.

```text
Общий провод JQ FTU ─────────────────────── U020 винтовая клемма: GND (чёрный Grove-провод)
JQ FTU #1, красный/белый (предыдущий) ───── U020 винтовая клемма: GPIO2 (жёлтый)
JQ FTU #2, жёлтый/зелёный (следующий) ───── U020 винтовая клемма: GPIO1 (белый)
U020: 5 V (красный) ─────────────────────── не подключать

AtomS3R Grove (G2/G1) ───────────────────── U020
Atomic CAN Base (G5/G6) ─────────────────── K-CAN2 CAN-H / CAN-L
```

**До первого включения проверьте клемму U020:** `GND` не должен иметь связи с двумя сигнальными проводами без нажатия кнопки. На разъёме U020 порядок контактов задаёт цвет Grove-кабеля, поэтому перед затяжкой винтов сверяйте его с фактическим кабелем. **Не соединяйте** общий провод FTU с кузовом автомобиля, 12 В, проводом CAN или цепью подушки безопасности/SRS. Когда руль отсоединён, проверьте мультиметром все три провода со стороны руля: каждая кнопка должна замыкать только свой сигнальный провод с общим. При длинном или зашумлённом кабеле добавьте компактный автомобильный формирователь входов либо хотя бы проверьте работу внутренних подтяжек и антидребезга на реальном жгуте до окончательной установки. Atomic CAN Base будет ответвлением существующей K-CAN2 и не содержит встроенного терминатора 120 Ом; не добавляйте его без отдельного подтверждения, что точка является концом шины.

## Начальное поведение

После нажатия с антидребезгом `buttonmap` отправляет кадр выбранного пресета один раз, ждёт заданное в пресете время и отправляет нейтральный кадр. Удержание кнопки не повторяет команду. Экран AtomS3R показывает название действия (`PREVIOUS` или `NEXT` в музыкальном пресете), `READY` либо ошибку передачи/шины. Для текущего музыкального пресета задержка равна 80 мс. Поставленный в очередь кадр не доказывает, что команда принята: на стенде проверьте трассу K-CAN2 и реакцию iDrive.

## Пресеты CAN

Аппаратные GPIO и антидребезг находятся в `include/buttonmap_config.h`. Настройки CAN вынесены в `include/can_presets.h`: каждый пресет содержит имя, скорость шины, полный кадр для каждой FTU-кнопки (`ID`, стандартный/расширенный формат, DLC и до 8 байт данных), подписи действий для экрана, нейтральный кадр и задержку перед ним. Драйвер TWAI настраивается на скорость активного пресета; неподдерживаемую скорость прошивка отклоняет при запуске.

Сейчас в таблице `kPresets` есть только `kMusic`. Он выбран строкой `kActivePresetIndex = 0` в `include/can_presets.h`; смена индекса требует пересборки и загрузки прошивки. Имя активного пресета отображается на экране и в USB-журнале при запуске. Интерфейс переключения пресетов на самом устройстве пока не задан. Для нового пресета, например поворотников, сначала подтвердите CAN-кадры, нейтральное состояние и поведение при удержании/отпускании кнопки на стенде. Не копируйте для него команды музыкального пресета как заглушку.

## План стендовой проверки

1. На выключенном контроллере, не подключённом к автомобилю, проверьте затяжку клеммы U020 и прозвоните общий провод FTU и контакты обеих кнопок.
2. Подайте на Atom питание по USB. По трассе CAN-анализатора убедитесь, что каждое нажатие даёт ровно одну команду и `[FC FF]` через 80 мс.
3. На целевой машине сначала пассивно запишите K-CAN2. Подтвердите скорость 100 кбит/с, стандартный ID `0x0A3`, DLC 2 и отсутствие конфликтующего кадра от другого блока.
4. Только после этого подключите Atomic CAN Base в нормальном режиме и проверяйте по одной команде со стабильным питанием. Если команда не работает, отключите модуль и вернитесь к пассивному захвату; не подбирайте другие шины или ID.

## Сборка и загрузка

```bash
git clone https://github.com/untoco/buttonmap.git
cd buttonmap
python3 -m venv .tooling/platformio
.tooling/platformio/bin/python -m pip install --upgrade pip "platformio==6.1.19"
.tooling/platformio/bin/pio run
.tooling/platformio/bin/pio device list
.tooling/platformio/bin/pio run --target upload --upload-port /dev/cu.usbmodem101
```

Используйте фактический порт из вывода `pio device list`: указанный в примере порт не универсален. Проект намеренно не загружает прошивку автоматически.

## Источники

- Руководство JQ Werks Madtrace, приложенное к задаче: обозначение проводов FTU #1/FTU #2 и предупреждения производителя по подушке безопасности и контактному кольцу.
- [Инструкция M5Stack для Atomic CAN Base](https://docs.m5stack.com/en/arduino/projects/atomic/atomic_can_base): связка с AtomS3R, `GPIO5` CAN TX и `GPIO6` CAN RX.
- [Документация M5Stack Unit 3.96 U020](https://docs.m5stack.com/en/unit/396port): переходник Grove ↔ VH3.96-4P и съёмная клемма.
- [Распиновка Grove M5Stack](https://docs.m5stack.com/en/learn/interface/grove): `GND`, `5 V` и две линии GPIO.
- [API Espressif TWAI](https://docs.espressif.com/projects/esp-idf/en/stable/esp32s3/api-reference/peripherals/twai.html): передача в нормальном режиме и обработка состояния bus-off.
